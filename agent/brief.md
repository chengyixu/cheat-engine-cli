Cheat Engine CLI (`cecli`) is a JSON-first, automation-safe process-memory interface. Use `--native` for eligible local macOS or Windows processes, or `--endpoint` for an upstream Cheat Engine `ceserver` or optional `cebridge`. It discovers targets, reads and scans memory, performs confirmation-gated mutations, and exposes the full remote protocol command set for authorized debugging, interoperability testing, modding, and security research.
