---
name: trigger
description: When an agent should use Cheat Engine CLI.
---

Use `cecli --native` for structured discovery, regions, reads, exact scans, or explicitly authorized writes against an eligible process on the current macOS or Windows computer. Use `cecli --endpoint host:port` for an upstream Cheat Engine `ceserver`, an optional `cebridge`, or remote-only features such as modules, threads, symbols, pipes, administration, and bounded debugger workflows.
