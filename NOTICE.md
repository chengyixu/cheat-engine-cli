# Notices and licensing status

This repository contains a clone of the upstream Cheat Engine source from `https://github.com/cheat-engine/cheat-engine` plus an independently implemented Go CLI that interoperates with the documented-in-source `ceserver` wire protocol.

As cloned on July 26, 2026, the upstream repository does not contain a repository-wide `LICENSE` file and GitHub does not report a detected repository license. Individual bundled components contain their own notices and license files, including `Cheat Engine/tcclib/COPYING`.

Do not assume that a new license added only to the CLI would relicense the upstream source tree. Review the provenance and applicable terms of every component before redistributing combined source archives or binaries. This notice is factual project hygiene, not legal advice.
